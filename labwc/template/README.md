# Noctalia LabWC Template

This template configures LabWC (an Openbox-compatible window manager) to automatically adapt its colors to the schemes generated by Noctalia, including a macOS-style window button layout (symmetrical squares) that is also recolored dynamically.

## Installation

1. Make sure to extract this `labwc` folder into your Noctalia templates or configuration directories. By default, you can leave it at `~/.config/labwc/template/`.

2. Add the following block to your Noctalia templates configuration file (`~/.config/noctalia/templates.toml`):

```toml
[theme.templates.user.labwc]
input_path = "~/.config/labwc/template/labwc.conf"
output_path = "~/.config/labwc/noctalia.conf"
post_hook = "bash ~/.config/labwc/template/apply.sh"
undo_hook = "bash ~/.config/labwc/template/undo.sh"
```

*(Note: Make sure the paths reflect the exact location where you extracted this `template` folder)*.

3. Reload Noctalia to apply the changes:
```bash
noctalia msg config-reload
```

## Features
- Automatic generation of minimalist square buttons (`10x10 px`).
- Fully dynamic interface (Windows use neutral background colors so buttons maintain good contrast).
- Close button unified with the `error` color.
- Minimize uses `secondary` and Maximize uses `primary`.
- Compatible with the real-time dynamic theming system (Hover color and inactive color).
